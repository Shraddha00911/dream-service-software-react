# Images

Drop image files here. The file name (without extension) must match the slot name used in the code,
and it will replace the placeholder automatically. Supported: png, jpg, jpeg, svg, webp, gif.

| File name (e.g. `logo.png`) | Where it is used |
| --- | --- |
| `logo` | Header logo |
| `trusted-1` … `trusted-5` | "Trusted by leaders" logos (ABC Home & Commercial, Clark Pest Control, J.P. McCall, Makot Service, Big Blue Bug) |
| `stat-lost-revenue` | Problem section – "~32%" card |
| `stat-dissatisfied` | Problem section – "1 in 4" card |
| `stat-ops-overhead` | Problem section – "7+ Tools" card |
| `platform-chart` | "One platform. Every handoff, handled." section |
| `icon-whatsapp`, `icon-linkedin`, `icon-facebook`, `icon-instagram` | Footer social icons |
| `badge-app-store`, `badge-google-play` | Footer app download badges |
| `logo-quacito` | Footer "Proudly powered by" logo |
